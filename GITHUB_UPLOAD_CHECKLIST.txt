SETHOURS v1.1 — GITHUB UPDATE

1. Extract this ZIP.
2. Replace every file in the GitHub repository with this package.
3. Confirm the icons and splash folders are uploaded.
4. Wait for GitHub Pages to finish deploying.
5. Delete the previous SetHours Home Screen shortcut.
6. Open the new Pages site in Safari and refresh.
7. Select Share > Add to Home Screen.

Important: iOS caches Home Screen icons aggressively. If the old/blank icon
persists, remove the site's cached Website Data in iPhone Safari settings.
