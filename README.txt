SETHOURS – TV TIMESHEET

This package includes the SetHours app and its custom Home Screen icon.

INSTALL ON IPHONE
1. Upload every file in this folder to a static host such as GitHub Pages, Netlify or Cloudflare Pages.
2. Open the hosted address in Safari on your iPhone.
3. Tap Share > Add to Home Screen.
4. Confirm the name “SetHours”.

The black production clapperboard and yellow stopwatch icon will appear on the Home Screen.

IMPORTANT
- Records are currently stored locally on that browser/device.
- Export CSV files regularly as a backup.
- Clearing Safari website data can remove locally stored records.
